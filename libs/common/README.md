# @fincommerce/common

Shared package for FinCommerce NestJS microservices.

## Includes

- Constants and metadata keys
- Common enums
- Standard API response contracts
- Custom application exception
- HTTP exception filter
- Response interceptor
- Correlation ID middleware
- Kafka event contracts and topic names
- RBAC decorators
- Base JWT guard

## Build

```bash
npm run build -w @fincommerce/common
```
